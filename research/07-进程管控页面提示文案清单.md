## 0. 待校对的疑点

1. **错字「选选」**：进程管理页、日志页「加入名单」弹窗，没勾名单时提示「请选选择要加入的黑/白名单！」（101 `processMana.js:434`、`log.js:456`）。
2. **终端数会显示成 0**：名单列表 3 处写了「…N 个组 M 台终端…」，M 取 `EPNUM`，后端列表不返回终端数，实际显示「N 个组 0 台终端」：「删除」按钮悬停（`list.js:245`）、「发布」按钮悬停（`list.js:264`）、已发布且已应用那一行的发布状态说明（`list.js:1390`、`1403`）。
3. **删除的两种说法不一样**：悬停说明「这些终端下次拉取策略时会清掉本地【名单】」；确认框「组内终端的【名单】会被清除。」（11-08 已改：悬停改成「删除后这些终端的【名单】会被清除」，两处说法一致）
4. **标点、语气不统一**：
   - 带「！」的只有「请输入【名单】名称！」（名单页创建弹窗照搬公共弹窗）和同事页面的几句，名单页其余提示都不带；（11-08 部分已改：名单页改成「请输入【名单】名称」，日志页没勾选改成「请先勾选要加入的日志」，概览改成「获取在线终端数失败，请稍后重试」，都不带「！」；仍带「！」的：进程管理页「请先选择要添加的数据！」、两页「请先选择要加入的黑/白名单！」、日志页「…请分开加入！」、公共新建弹窗「请输入【名单】名称！」）
   - 「当前暂无数据～」用全角～，同事页面用半角 ~；（11-08 已改：名单页改成「当前暂无数据」，日志页「…创建~」改成「请点右上角「新建【名单】」创建」，都不带～ / ~；进程管理页「…按钮创建~」仍是半角 ~）
   - 应用到组弹窗「(每个分组只能应用一个白/黑名单)」是半角括号。（11-08 已改：「（每个组只能应用一个白名单或黑名单）」，全角括号，「分组」改「组」）
5. **同一个东西叫法不同**：
   - 日志页筛选叫「文件路径」，其他页面叫「进程路径」；
   - 日期框占位：名单页「开始日期」，日志页「请选择开始日期」；
   - 计数单位：名单列表「已筛选出 0 个，共 0 个」，名单进程页「已筛选出 0 条，共 0 条」；
   - 策略页写「信任白名单」，其他地方叫「白名单」；
   - 日志页「动作」筛选项叫「拦截」，表格里显示「已拦截」。
6. **新建名单有两个弹窗**：进程管理、日志页用公共弹窗（`layout.html`）：「描　述」（中间有两个空格，源码是 `&nbsp;&nbsp;`）、按钮「关闭 / 确定」；名单页自己的弹窗：「描述」、按钮「取消 / 创建（编辑时是保存）」。

### 1.4 表格里的提示

- 进程数：「有 a 个新增进程还没发布」「有 b 个移除的进程还没发布」
- 应用范围：没有时显示 ---，悬停「还没设置应用范围（终端上没有这条【名单】）」；有时悬停「已应用到 N 个组，点击查看已应用组」（M > 0 时中间多「，组内共 M 台终端」）
- 展开 / 收起：「展开」「收起」
- 没有数据：「没有符合条件的【名单】，清空筛选条件后重试」

### 1.5 发布状态问号：表头说明

- 总说明：发布 = 把当前进程内容定稿；真正下发到终端看「应用范围」：已发布的【名单】选了应用范围就自动下发。颜色：灰 没进程，蓝 等着发布，绿 定稿了，橙 有没发布的变更。
- ---：还没有任何进程，不能发布；先到「进程」页添加
- 待发布：加了进程（0 +N），还没发布过；点「发布」定稿，之后才能设置应用范围
- 已发布：内容定稿了，没有待发布的增减。应用范围是 --- 的还没下发到终端，选了应用范围就自动下发；改应用范围也自动下发，不用再发布
- 有变更：发布过，之后进程有增减（+N / -N）还没发布，终端上还是旧版本；点「发布」自动下发。有变更时不能改应用范围；已发布的【名单】至少保留 1 个进程
- 流转图：添加进程、发布、进程增减、选 / 改应用范围 → 自动下发（状态不变；有变更时不能改范围）

### 1.6 发布状态问号：每一行的说明

- 没进程：还没有任何进程，不能发布。／ 下一步：到「进程」页添加进程，然后点「发布」。
- 待发布：加了 N 个进程，还没发布过，终端上没有这条【名单】。／ 下一步：点「发布」把内容定稿，再设置应用范围（自动下发）。
- 已发布、已应用（M 目前显示 0，见疑点 2）：内容已定稿（K 个进程），已应用到 N 个组 M 台终端：在线终端下次心跳（默认 5 分钟内）生效，离线终端上线后生效。／ 不需要操作。改应用范围会自动下发，组内终端下次心跳生效。
- 已发布、没应用：内容已定稿（K 个进程），还没设置应用范围，终端上没有它。／ 下一步：点「应用到组」，选完自动下发。
- 有变更：发布过（K 个进程），之后新增 a 个、移除 b 个还没发布（已应用时接「，终端上跑的还是旧版本。」，否则接「。」）
  - 下一步（已应用）：下一步：点「发布」，会自动下发到终端。有变更时不能改应用范围。
  - 下一步（没应用）：下一步：点「发布」把变更定稿，再设置应用范围。
  - 发布后会变成 0 个进程：发布后进程数会变成 0，不能发布；要清掉这条【名单】请直接删除。

### 2.1 手动添加进程弹窗
