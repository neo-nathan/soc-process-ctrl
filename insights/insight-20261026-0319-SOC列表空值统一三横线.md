# SOC 列表空值统一显示三横线

**场景**：2026-10-26 用户指出名单列表「应用范围 / 发布状态 / 描述」空值显示 `--`，要求改成 `---`；排查后名单列表其余列、名单进程页、创建 / 编辑弹窗、设计文档 01、demo 都用的是 `--`，全部返工（svn r72068，`changelog/log-20261026-0309-名单列表空值改三横线.md`）。

**现象 / 坑**：同事写的进程管控页面（`log.js`、`overview.js`、`processMana.js`、`proDetail.js`）和策略中心空值都是 `---`；名单页从 demo 起就写成 `--`，设计文档 01 也跟着写 `--`，一路带进源码，没人对照过现有页面。原始需求第 100-104 行写的是 `--`（指空名单状态），但 SOC 页面实际约定是 `---`。

**结论**：SOC 页面上的空值、「空名单」这类状态的显示文字一律写 `---`。设计、demo、源码三处要一致；引用需求原文的地方照原文。

**检查清单**：

1. 新写列表 / 信息条 / 弹窗时，空值写 `---`（灰色样式照本页现有写法）。
2. 写完用精确匹配查有没有残留的两横线（排除 `---`、`<!--`、`-->`、`left--` 这类）：Python 正则 `(?<![-!<|])--(?![->a-zA-Z])`。
3. 发布状态这类「显示文字也被代码拿来比较」的值（如 demo 里 `status === '---'`、配色表的键），要连同比较和配色一起改，改完打开页面确认状态颜色和筛选正常。
4. 以前的验收脚本断言的是 `--`，是当时的证据不回改；再跑之前先改断言。
