# 对齐策略中心样式要量浏览器实际值，别照代码字面

**场景**：2026-10-25 把白 / 黑名单页、名单进程页和弹窗的样式改成和策略中心一致（[changelog](../changelog/log-20261025-2146-名单页样式对齐策略中心.md)）。之前名单页是照着策略中心的代码「字面意思」抄的，结果有几处看起来不一样。

**现象 / 坑**：

1. **字体：body 的字体名写错，退回浏览器默认字体。** 公共样式 `index.css` 给 body 写的是 `font-family: "NotoSansHans,Microsoft YaHei"`，整串被引号括成**一个**字体名，系统里没有这个字体，于是退回浏览器默认字体。策略中心靠外壳 `.strategy_content{font-family:"Microsoft YaHei"}`（`assetbehaotherstra.css`）另外指定了字体，名单页没有这层外壳，继承的就是写错的 body 字体。
   - 按钮、输入框浏览器本来就不继承字体，两边都用公共样式给的字体，这个本来就一致，不用管。
2. **展开行：`border-bottom` 只写颜色，实际效果是去掉边线。** 策略中心 `view/strategy/openLine.js:52` 写的是 `$(td).css('border-bottom', '#fff')`，看着像「把下边线改成白色」，实际上这种简写把线型重置成了 `none`，101 实测是 `0px none`。两行中间那条线，其实是下面按钮行单元格的上边线（`.strategy_content .bootstrap-table .table>tbody>tr>td{border-top:1px solid #eee9e9}`）。
   - 名单页原来照字面写成 `border-bottom-color:#fff`（白色实线）。表格是合并边框，白线把这条线盖掉了，所以看起来「没有底边」。
   - 按钮行高 40px 也是 `openLine.js` 写的行内样式，样式文件里搜不到。
3. **拖拽：`RsCore.alertBoxDrag` 会吞掉点击。** `js/core.js:1811` 给目标元素绑 `click → return false`，点击既不会往上传，也执行不了默认动作。如果像策略中心那样把 `alert_drag` 加在整个 `.modal-header` 上，标题栏里靠 bootstrap `data-dismiss` 关闭的 × 就失效了。策略中心的 × 能用，是因为 `strategy/index.js:1368 bindAlertHandle` 另外直接给 `.close` 绑了关闭事件。
   - 这个函数只给调用那一刻已经存在的元素绑定，而且重复调用会重复绑定。公共布局（`home.js`）的消息弹窗也会调用 `alertBoxDrag('.alert_drag')`。

**结论**：

- 照抄现有页面的样式，以浏览器里的实际值为准，别看代码猜：在 101 上两边用 `getComputedStyle` 读同一批属性对照。来源说不清时，把当前页面所有样式表里匹配这个元素的规则列出来。行内样式和 JS 写进去的样式也要看（`el.getAttribute('style')`）。
- 字体要在自己页面的根元素上指定 `font-family: "Microsoft YaHei"`，别依赖 body。
- 拖拽类加在标题 `h3` 上（公共布局 `layout.html` 也是这样写的），调用时只传本页容器里找到的元素：`RsCore.alertBoxDrag(view.find('.alert_drag'))`，不要传全局选择器。
- 想图省事整页套 `.strategy_content` 之前，先在浏览器里临时加上这个类，比一下所有元素加类前后的样式差异。10-25 实测这样会改乱高级查询区，还会多出 20px 外边距，所以只能挑需要的规则搬。

**检查清单**：

1. 两边在 101 上量：字体、字号、粗细、颜色、行高、单元格高度和上下边线、行悬停底色（要用真实鼠标悬停，JS 触发不了 `:hover`）、展开后主行和按钮行的边线和行高、工具栏高度、弹窗标题栏 / 标题 / 正文 / 底部按钮。
2. 用 `$._data(el,'events').mousedown.length` 确认每个弹窗标题只绑了 1 次；切到别的页面再回来，还是 1 次。
3. 用真实鼠标拖动弹窗，确认位置变了；再点 ×，确认弹窗关了、遮罩也清掉了。
4. 和 [照搬弹窗要带外壳类名](insight-20261023-0443-照搬现有页面弹窗要带外壳类名.md) 一起看：搬弹窗用外壳类名；整页对齐只能挑规则搬，因为套外壳会改乱整页。
