# 在 101 共享开发环境上联调、上传和实测的坑

**场景**:PL-01 黑白名单列表页(10-21～10-22)在 101 上做前端、mock、上传和浏览器验收,后端由同事在同一台机器上同时开发。证据见 `changelog/log-20261021-0530-实施PL-01.md` 各段(08:5x 会话丢失、00:25 timeRange、01:38 policytype、04:37 布局文件被覆盖)。

**现象 / 坑**:

1. 用裸 `fetch` / `$.post` 发 POST 确认会话,后端 `My.php:56-63` 发现没有正确的 RSTOCKEN 头就直接销毁会话,用户得重新登录。
2. 后端同事在联调期间改了接口:`getWBList` 的 `timeRange` 缺省值变成 1(只给本周)、名单类型参数从 `type` 改成 `policytype`、`SYSTYPE` 改成首字母大写——前端没动,页面却突然空表或被拦。
3. 同事同步部署时用他的旧副本把我们上传的公共文件(`view/processManage.js`)覆盖回开工版,名单页「创建 / 编辑」在 101 上失效,而本地一切正常。
4. 把「被拦住、没测到」归因为「同事刚改了某文件」,结果真实原因是后端返回的写法和前端判断大小写不一致。
5. 在页面里用 `$.get` 取 `.js` 文件核对版本,jQuery 会把它当脚本执行,AMD 匿名 `define` 进了 RequireJS 队列,引发一次「Mismatched anonymous define()」异常。
6. SSH 端口通、但不回版本行时,先怀疑本机代理,实际是 101 上 sshd 卡死。
7. 本机 shell 是 zsh:把 ssh 选项放进变量 `SSHO="-o A -o B"` 再写 `ssh $SSHO …`,zsh 不按空格拆词,整串当成一个参数,ssh 直接失败;再配上 `2>/dev/null` 吞掉报错,「上传前核指纹」的输出就是空的。PL-03 第一次上传因此跳过了核对(`changelog/log-20261022-2150-实施PL-03.md`);10-22 发布切真接口时又踩一次,因为判断写成「指纹对上才传」,当场停住(`changelog/log-20261022-2231-发布切真实releaseWBList接口.md`)。 10-26 名单页空值改 `---` 上传时又写成 `O="-o …"`,ssh 当场报「extra arguments」停下、没有误传(`changelog/log-20261026-0309-名单列表空值改三横线.md`)。正确写法:zsh 用数组 `O=(-o A -o B)`,再写 `ssh $O …`。

**结论**:

- 确认会话只用页面自带的 `RsCore.ajax`(自动带令牌),任何角色都不许裸 POST。
- mock 或前端调真接口时,凡会影响「取全量」的参数(如 `timeRange`)显式写死;参数改名期间新旧名一起带。
- 上传后、尤其收尾实跑前,重核 101 上每个上传文件的指纹;被覆盖时先确认对方版本有没有新内容(与基线逐字节比),再按上传规则处理,并告诉用户去协调同事。
- 定性「环境问题 / 不算本任务不通过」前,先定位拦截它的那一行代码,比对改动前后。
- 核对 101 文件只用 SSH md5 或网页取回算指纹的脚本,不在页面里 `$.get` 脚本文件。
- SSH 异常先做对照(换目标主机、在服务器本机查 sshd),再归因。
- ssh / scp 选项直接写在命令里,不放进变量;上传写成「指纹对上才传、否则停」,不先传后核;不用 `2>/dev/null` 吞 ssh 报错。

**检查清单**:

1. 会话检查命令里有没有裸 `fetch` / `$.post`?有就换成 `RsCore.ajax`。
2. 调真接口的参数里,影响返回范围的参数是不是显式给了值?
3. 收尾前:101 上每个上传文件 md5 = 本地?属主权限对吗?
4. 写「环境阻塞」前:拦截代码在哪一行?改动前后一样吗?
5. 浏览器里有没有用 `$.get` / `$.getScript` 拉 `.js`?
6. 上传命令里有没有 `$变量` 装着多个 ssh 选项?核指纹的输出是不是空的?
