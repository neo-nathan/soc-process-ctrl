# 名单进程页刷新挪到工具栏

- 时间：2026-10-26 03:27 EDT
- 触发：用户截图指出「白名单进程列表 右上角的刷新图标 应该跟高级搜索一行 而不是单独一行」

## 改了什么

- `ESMCenterST/public/esm/view/processManage/bwlistProc.html`：删掉信息条最右的刷新图标（`.js_procm_proc_refresh`）；工具栏注释改为右边是「高级搜索」「刷新」「列设置」。
- `bwlistProc.js`：表格 `showRefresh` 由 `false` 改 `true`，用表格自带的刷新按钮（按钮顺序同名单列表页：高级搜索 → 刷新 → 列设置）；点击改为委托绑定 `.procm-proc-main .fixed-table-toolbar button[name="refresh"]`，仍调 `fetch(false)` 同时重取进程行和信息条。
- `css/processManageList.css`：删掉 `.procm-proc-refresh` 两条样式。
- `demo/白名单进程列表.html`：信息条右侧的刷新 / 列设置挪到工具栏「高级搜索」后面。
- 设计 01：版本记录加 10-26 补充；8.6 加一条；9.1.7「取数」里「点信息条『刷新』」改为「点表格工具栏『刷新』」。

## 为什么

- 用户要求刷新与高级搜索同一行。名单列表页本来就用表格自带的刷新（`list.js` `showRefresh: true`），照它做外观一致。
- 进程表是本地数据（没有 `url`），插件自己的 `refresh` → `initServer` 在没有 `url` 时直接返回（`dep/table/bootstrap-table.js:1877`），所以不会和我们的 `fetch` 重复请求；委托绑定在进程视图容器 `S.$pane` 上，不会影响名单列表页的刷新。
