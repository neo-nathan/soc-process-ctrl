# 名单页发布确认与成功提示简化

- 时间：2026-11-05 01:38 EST
- 触发：用户给出发布确认框截图（「确定发布「test7」吗？」「发布后才能应用到组」），提了 4 条：
  1. 第一句改为「确定发布白名单 / 黑名单「X」吗？」，按发布的名单动态变化；
  2. 去掉「发布后才能应用到组」；
  3. 发布成功只提示「发布成功」，不再按情况提示「已发布，组内终端下次心跳（默认 5 分钟内）生效」「已发布，应用到组后下发」；
  4. 应用到组确认后只提示「应用成功」，不再带心跳那半句。

## 改了什么

- SOC 源码 `public/esm/view/processManage/list.js`：
  - `publishConfirmHtml(row, name)`：只输出一句 `确定发布 + name + 「X」吗？`，name 由调用方传 `op.cfg.name`（白名单页「白名单」、黑名单页「黑名单」，调用处原本就传了这个参数，发布这边之前没用）；第二句整行去掉。
  - 删掉 `publishOkMsg` 和两个常量 `TXT_PUBLISH_APPLIED`、`TXT_PUBLISH_UNAPPLIED`，新增 `TXT_PUBLISH_OK = '发布成功'`；发布确认框的 `okMsg` 固定返回它。
  - `TXT_APPLY_OK` 改为 `'应用成功'`。
  - 相关注释同步（确认框配置、`submitConfirm`、`submitGroup`）。
  - `TXT_HEARTBEAT` 保留：发布按钮的悬停说明还在用。
- `architecture/01-进程管控设计文档.md`：顶部加「11-05 补充六」；7.4「页面发布确认框」、8.8 第 12 条、发布接口「页面提示」、应用到组接口「出参」四处改新文案，旧文案留作「曾为」。
- `demo/白名单列表.html`、`demo/黑名单列表.html`：演示用的发布提示改「发布成功」，应用到分组的演示提示改「应用成功」。demo 没有发布确认框，不涉及第 1、2 条。

## 为什么

用户定的文案：确认框写清发布的是哪种名单，成功提示只说结果，不解释生效时间。

## 怎么验证

- `node --check list.js`、`acorn --ecma5 list.js` 通过。
- 用 node 抽出 `publishConfirmHtml` 和两个常量实跑：
  - `({PNAME:'test7'}, '白名单')` → `<div>确定发布白名单「test7」吗？</div>`；
  - `({PNAME:'a<b'}, '黑名单')` → `<div>确定发布黑名单「a&lt;b」吗？</div>`（名称已转义）；
  - `TXT_PUBLISH_OK` = 「发布成功」，`TXT_APPLY_OK` = 「应用成功」。
- grep：`publishOkMsg`、`TXT_PUBLISH_APPLIED/UNAPPLIED`、「发布后才能应用到组」在源码里无残留；成功提示只剩 `RsCore.msg.success` 两处，分别用这两个常量。设计 01 里的旧文案只剩「曾为」说明和 10-22 的历史实测记录。
- 本地 md5：`list.js` 改前 `8a4a8d92`，改后 `1f36afe9`；`list.html` 没改。
